If a club stops paying

The radios, the map, chat, Ask for a Hand and the after-sunset alert keep working. Only the club's shared setup and admin tools freeze until it renews.

Do members pay anything?

No. One subscription covers the club. Members scan the club's QR code and join.

Do we need cell service or Wi-Fi on the property?

No. Field features run over the radios. The internet is only used to set up the club and sync changes.

What radios does it work with?

Stock Meshtastic radios with GPS. No custom firmware.

Is this an emergency service?

No. Ask for a Hand pings your party or club. For emergencies, call 911 from your phone if you have service.

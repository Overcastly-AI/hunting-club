Safety is never behind a paywall

If a club's subscription ends, the radio, chat, Ask for a Hand and overdue alerts keep working. Only the shared setup and admin tools pause.

Billing questions

Who pays?

The club pays once for everyone. Members join free.

How is it billed?

$10 a month or $100 a year per club, by card through Stripe, after a 14-day free trial.

Can I cancel?

Yes. Cancel anytime before day 14 and you won't be charged.

What happens if we stop paying?

The radio, chat, Ask for a Hand and overdue alerts keep working. Only the shared setup and admin tools pause.

Do members need accounts?

Club members sign in once with a code sent to their email. There is no password.

Is the radio included?

No. Each hunter needs a Meshtastic radio with GPS, sold separately.
